# Age Calculator

## Description
Calculate your exact age in years, months, days, hours, and minutes!

## How to Play
1. Run: `python game.py`
2. Enter your birth date
3. See your detailed age breakdown

## Python Concepts
- datetime module
- Date arithmetic
- Formatted output
