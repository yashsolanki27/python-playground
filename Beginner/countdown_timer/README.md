# Countdown Timer

## Description
A visual countdown timer with progress bar! Set hours, minutes, and seconds, then watch it count down with a nice animation.

## How to Play
1. Run the game: `python game.py`
2. Enter hours, minutes, and seconds
3. Press Enter to start
4. Watch the countdown
5. Press Ctrl+C to stop early

## Python Concepts Learned
- **time Module**: Sleep and timing
- **While Loops**: Countdown loop
- **String Formatting**: HH:MM:SS display
- **ASCII Animation**: Progress bar
- **Keyboard Handling**: Ctrl+C interrupt
