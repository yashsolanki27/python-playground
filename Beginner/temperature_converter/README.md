# Temperature Converter

## Description
Convert temperatures between Celsius, Fahrenheit, and Kelvin instantly!

## How to Play
1. Run: `python game.py`
2. Enter temperature value
3. Select source and target units
4. See the converted result

## Python Concepts
- Arithmetic operations
- Functions for each conversion
- Input validation

## Sample Output
```
Enter temperature: 100
From: 1=Celsius, 2=Fahrenheit, 3=Kelvin
Select (1/2/3): 1

To: 1=Celsius, 2=Fahrenheit, 3=Kelvin
Select (1/2/3): 2

  ✅ 100.0°C = 212.00°F
  (Celsius to Fahrenheit)
```
