# Python Learning Games

A collection of interactive Python games designed to teach programming fundamentals through hands-on practice.

## Overview
This project contains 20+ Python games organized into three difficulty levels:
- **Beginner** (10 games): Core Python concepts
- **Intermediate** (9 games): Data structures, utilities, and logic
- **Advanced** (3 games): OOP and complex programming

## Games Included

### Beginner Level
| Game | Description | Concepts Learned |
|------|-------------|------------------|
| Number Guessing | Guess a random number | Variables, loops, conditionals |
| Rock Paper Scissors | Classic hand game | If-else, random module |
| Calculator | Basic arithmetic | Functions, error handling |
| Dice Rolling | Virtual dice with ASCII art | Random, lists, statistics |
| Word Scramble | Unscramble letters | String manipulation, lists |
| Password Generator | Secure password creation | secrets module, security |
| Number to Words | Convert numbers to text | String building, math |
| Tip Calculator | Calculate tips and splits | Arithmetic, formatting |
| Mad Libs | Fill-in-the-blank stories | String formatting, input |
| Countdown Timer | Visual timer with animation | time module, loops |

### Intermediate Level
| Game | Description | Concepts Learned |
|------|-------------|------------------|
| Hangman | Word guessing game | Lists, strings, loops |
| Tic-Tac-Toe | Classic board game | 2D lists, game logic |
| Quiz Game | Multiple choice quiz | Dictionaries, score tracking |
| Expense Tracker | Track spending | File I/O, JSON, summarization |
| Pomodoro Timer | Productivity timer | time module, counters |
| Flashcard App | Study flashcards | Lists, random, persistence |
| Markdown Converter | Convert MD to HTML | Regex, string processing |
| JSON Formatter | Format/validate JSON | JSON module, error handling |
| QR Code Generator | ASCII QR codes | Encoding, hash functions |

### Advanced Level
| Game | Description | Concepts Learned |
|------|-------------|------------------|
| Blackjack | Card game 21 | OOP, complex logic |
| Snake Game | Classic snake | OOP, pygame, animations |
| Inventory System | Item management | OOP, file I/O |

## Quick Start

### Prerequisites
- Python 3.11 or higher
- Git (optional, for cloning)

### Installation
```bash
# Clone the repository
git clone https://github.com/yashsolanki27/python-playground.git

# Navigate to project directory
cd python-playground

# No installation required - games use Python standard library
```

### Running a Game
```bash
# Navigate to game directory
cd Beginner/number_guessing

# Run the game
python game.py
```

## Learning Path

### Phase 1: Beginner (Start Here)
1. **Number Guessing Game** - Learn variables, loops, conditionals
2. **Rock Paper Scissors** - Master if-else statements
3. **Calculator** - Understand functions and error handling
4. **Dice Rolling Simulator** - Practice random module and statistics
5. **Word Scramble** - Work with strings and lists
6. **Password Generator** - Learn about security and the secrets module
7. **Number to Words** - Practice string building and math
8. **Tip Calculator** - Apply real-world arithmetic
9. **Mad Libs** - Have fun with string formatting
10. **Countdown Timer** - Learn about time and loops

### Phase 2: Intermediate
11. **Hangman** - Work with lists and strings
12. **Tic-Tac-Toe** - Implement 2D data structures
13. **Quiz Game** - Use dictionaries and score systems
14. **Expense Tracker** - Learn file I/O and data persistence
15. **Pomodoro Timer** - Build productivity tools
16. **Flashcard App** - Create study applications
17. **Markdown Converter** - Process text with regex
18. **JSON Formatter** - Work with structured data
19. **QR Code Generator** - Generate visual patterns

### Phase 3: Advanced
20. **Blackjack** - Apply object-oriented programming
21. **Snake Game** - Create graphical games with pygame
22. **Inventory System** - Build data persistence systems
